GitHub Pages workflow for the personal user site https://m1hasmad.github.io/

This workflow is intended for a repository named exactly:
  m1hasmad.github.io

It builds Angular with --base-href / because this is a user site at the domain root.
The Angular application build output configured in this project is:
  dist/mikhail-flight-log/browser

Install by extracting this archive into the root of your Angular project, preserving
folder structure. Then create the GitHub repository, choose GitHub Actions as the
Pages source, and push the main branch.
